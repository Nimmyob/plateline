# Plateline
Plateline is a web application that translates handwritten menus from photographs.

## Features
- Upload a photograph.
- Translate handwritten text.
- Simple and user-friendly interface.

## Technologies
- HTML
- CSS
- JavaScript

How to Run the Website Locally

Requirements

- Visual Studio Code
- Google Chrome or another web browser
- Live Server extension

Installation Steps

1. Download or clone this repository from GitHub.

2. Open the project folder in Visual Studio Code.

3. Install the Live Server extension:
   
   - Open Extensions ("Ctrl + Shift + X").
   - Search for Live Server.
   - Install Live Server by Ritwick Dey.

4. Open "index.html".

5. Right-click inside the HTML editor.

6. Select Open with Live Server.

7. Your website will open in your default browser.

Local Development

The website will run at:

"http://127.0.0.1:5500/index.html"

Any changes saved to "index.html" will automatically refresh in the browser.
